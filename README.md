# Successive Approximation Register (SAR) ADC – Architecture Study

This project focuses on studying the architecture and working principle of a Successive Approximation Register (SAR) Analog-to-Digital Converter (ADC). The objective was to understand how an analog input signal is converted into a corresponding digital output using the successive approximation technique.

The study examined the major building blocks of a SAR ADC, including the Sample-and-Hold circuit, Comparator, Capacitive Digital-to-Analog Converter (CDAC), and SAR Logic. The role of each block in the conversion process was analyzed, along with how these blocks work together to determine the digital representation of the input signal.

The successive approximation algorithm was studied in detail, where the SAR logic progressively determines each digital bit by comparing the input signal with the voltage generated by the CDAC. The conversion process was analyzed from the most significant bit (MSB) to the least significant bit (LSB).

The project also involved studying important SAR ADC design trade-offs, particularly the relationship between conversion speed, power consumption, and resolution. This provided a better understanding of the architectural considerations involved in designing efficient data converters.

### Topics Studied

* SAR ADC Architecture
* Sample-and-Hold Circuit
* Comparator
* Capacitive DAC (CDAC)
* SAR Logic
* Successive Approximation Algorithm
* ADC Resolution and Conversion Speed
* Power-Performance Trade-offs

### Key Learning

* Understanding SAR ADC operation
* Understanding the function of individual ADC building blocks
* Understanding the bit-by-bit conversion process
* Analyzing speed, power, and resolution trade-offs
* Developing familiarity with ADC architecture and data-converter design
